## 维护约定

- **设计/设定改动**：改对应章节文件，并在 [09-变更记录](09-变更记录.md) 增加一行；不要在 `Oathbreaker.md` 上直接改。
- **Bug/崩溃/数值不一致**：记录到 [08-错误记录](08-错误记录.md)；兼容性风险记录到 [10-待确认决策与风险](10-待确认决策与风险.md) 的风险表。
- **代码改动**：新增/重命名/删除类或方法后，同步更新 [CLASS_INDEX.md](CLASS_INDEX.md)（维护清单见该文末）。
- **新增章节**：在 [00-大类划分说明](00-大类划分说明.md) 补一行，再新建本目录下的编号文件，并在上表登记。
- **原始文档**：`Oathbreaker.md` 仅作历史存档，不再更新；拆分文件才是工作副本。

## 格式说明

原文由渲染后的 Markdown 粘贴而来，部分 `##` / `###` 标题、表格的 `|---|` 分隔行和代码围栏丢失。拆分脚本按章节编号与内容结构恢复了这些格式：

- 章节标题 → `#`，二级小节 → `###`；
- Tab 分隔的“伪表格” → 标准 Markdown 表格；
- 裸 `json` / `java` / `text` 标记 → 代码围栏；
- 调整了标题、表格、代码块前后的空行。

如需修改正文，直接编辑对应章节文件即可；`build_docs.py` 与 `verify_docs.py` 只用于本次拆分，已从工作区移除。

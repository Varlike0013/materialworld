# Spirit World 项目总览

## 1. 项目定位

Spirit World 是《MaterialWorld》的附属 Mod（addon），围绕三条资源链构建玩法：

1. **精神力（Spirit）**：玩家自身的主动资源，用于技能消耗、飞行、护盾、工具召唤等。
2. **灵视（Vision）**：由累计消耗的精神力推导出的成长等级，配合灵视碎片与灵视点解锁技能树。
3. **魔力（Mana）**：由聚集器采集、中继器传输、核心存储的 World 资源，用于合成魔力砖与各类水晶。

项目标识：`mod_id = spiritworld`，主类 `com.varlike.spiritworld.SpiritWorld`。

## 3. 包结构地图

| 包 | 职责 |
|---|---|
| `com.varlike.spiritworld` | Mod 入口、COMMON/CLIENT 配置、客户端引导 |
| `.api` | 方块信息悬浮提示接口 |
| `.registry` | 物品/方块/BlockEntity/菜单/实体/附魔/护甲材质/数据组件注册 |
| `.block` | 精神核心、聚集器、中继器、魔力建筑方块、屏障及对应 BlockEntity |
| `.capability` | 玩家精神力与技能进度 `PlayerSpirit`、持久化、登录/tick 事件 |
| `.skill` | 技能树、数值表、技能计算、飞行/扫描/工具构建、运行时魔力配方 |
| `.network` | NeoForge payload、魔力网络节点抽象、拓扑与效率计算 |
| `.item` / `.entity` / `.component` | 自定义物品行为、魔力合金箭实体、DataComponent |
| `.event` | 套装、附魔、护盾、工具、击杀碎片、口袋维度命令与事件 |
| `.world` | 口袋维度分配、SavedData、区块加载、生成任务、访客请求 |
| `.client` | 客户端数据镜像、按键、屏幕注册、客户端事件 |

| `.client.skill` | 技能树/装配/扫描配置/环形菜单 GUI 与世界标记渲染 |
| `.datagen` | 物品模型、方块状态、双语语言、配方数据生成 |

## 4. 构建与运行

```powershell
# 构建产物
.\gradlew.bat build

# 生成资源（配方、模型、方块状态、语言文件）
.\gradlew.bat runData

# 本地运行
.\gradlew.bat runClient
.\gradlew.bat runServer
```

生成资源输出到 `src/generated/resources`，由 `build.gradle` 加入主资源集。

## 5. 架构原则

- **服务端权威**：玩家精神力、技能、魔力网络、口袋维度领地均由服务端计算；客户端只保留镜像缓存。
- **数据驱动展示**：HUD、悬浮信息、技能树 GUI 通过 AetherUI 渲染，逻辑与绘制分离。
- **静态注册表 + DeferredRegister**：所有游戏对象统一在 `registry` 包注册。
- **双语集中维护**：`ModLanguageProvider` 一个类中同时写中英文，注册两个 locale 实例生成两份 JSON。
- **运行时配方与数据生成配方分离**：原版合成由 datagen 产出；魔力核心合成表在 `ManaCraftingRecipes` 中维护。

# 数据生成与资源配置

## 1. 数据生成器入口

`datagen/DataGenerators.gatherData(GatherDataEvent)` 注册 5 个 provider：

| Provider | 生成内容 | 输出示例 |
|---|---|---|
| `ModItemModelProvider` | 24 个物品的手持模型 | `assets/spiritworld/models/item/*.json` |
| `ModBlockStateProvider` | 三档聚集器、魔力方块/台阶/楼梯、精神核心的方块状态与模型 | `assets/spiritworld/blockstates/*.json`、`models/block/*.json` |
| `ModLanguageProvider` | 中英文语言文件 | `assets/spiritworld/lang/en_us.json`、`zh_cn.json` |
| `ModRecipeProvider` | 原版合成/熔炼配方与 advancement | `data/spiritworld/recipe/*.json`、`advancement/*.json` |
| `DataGenerators` | 注册入口（本身不产出文件） | — |

运行命令：

```powershell
.\gradlew.bat runData
```

输出到 `src/generated/resources`，并通过 `build.gradle` 的 `sourceSets.main.resources` 加入构建。

## 2. 双语语言生成设计

`ModLanguageProvider` 参考 AetherUI 的做法，采用**单类双 locale**：

```java
public ModLanguageProvider(PackOutput output, String locale) {
    super(output, SpiritWorld.MOD_ID, locale);
    this.isChinese = locale.equals("zh_cn");
}

private void translate(String key, String en, String zh) {
    add(key, isChinese ? zh : en);
}

private void item(Item item, String en, String zh) {
    add(item, isChinese ? zh : en);
}
```

所有文案集中在 `defineTranslations()` 中，每条调用同时写中英文。`DataGenerators` 注册两个实例分别生成 `en_us` 与 `zh_cn`。

优势：

- 新增 key 不会漏掉某一种语言。
- 中英文条目相邻，便于校对日期/占位符一致性。
- 与 AetherUI 的维护方式一致，降低跨项目切换成本。

注意事项：

- 翻译中的 `%d`、`%s`、`%%` 占位符必须与运行时 `Component.translatable(...)` 的实参顺序一致。
- 生成结果当前为 334 个 key。

## 3. 运行时配方 vs 数据生成配方

| 类型 | 维护位置 | 用途 |
|---|---|---|
| 原版合成/熔炼 | `datagen/ModRecipeProvider` | 普通配方，产出 JSON 数据包 |
| 魔力核心合成 | `skill/ManaCraftingRecipes` | 12 条运行时配方，由 `SpiritCoreBlockEntity` 直接读取，不生成 JSON |

新增核心配方应修改 `ManaCraftingRecipes`，不要写进 `ModRecipeProvider`；新增普通合成才使用 datagen。

## 4. 手写资源

`src/main/resources` 中保留少量手写 JSON：

- `data/spiritworld/dimension/pocket_world.json`
- `data/spiritworld/dimension_type/pocket_type.json`
- 附魔相关 JSON（如存在）

这些资源与维度机制强耦合，未纳入 datagen。贴图位于 `assets/spiritworld/textures/`，包含方块、物品、盔甲与箭矢等约 40 张 PNG。

## 5. 资源校验建议

1. 修改语言/配方/模型后运行 `runData`。
2. 检查 `src/generated/resources` 是否有新增或删除的 JSON。
3. 语言文件需确认中英文 key 数一致、占位符一致。
4. 构建时 `processResources` 会自动展开 `src/main/templates` 中的模组元数据。

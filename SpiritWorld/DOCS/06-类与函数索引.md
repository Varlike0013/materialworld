# 类与函数索引

> 路径均相对于 `src/main/java/com/varlike/spiritworld/`。本索引覆盖对架构理解重要的类与公开/关键方法，私有绘图细节不逐一列出。

## 根包

| 类 | 职责 | 关键成员 |
|---|---|---|
| `SpiritWorld` | Mod 主入口，注册全部 DeferredRegister、能力、配置与创造标签 | `MOD_ID`、`SPIRIT_TAB_GROUP`、构造器、`commonSetup(FMLCommonSetupEvent)` |
| `SpiritWorldClient` | 客户端启动引导 | `onClientSetup`、`onRegisterScreens` |
| `Config` | COMMON 配置与静态镜像 | `loadValues()`、`onReload(ModConfigEvent.Reloading)`、恢复/同步/扫描/口袋维度相关字段 |
| `ClientConfig` | CLIENT 配置 | `showSpiritBar`、`showSpiritText`、`scanIconMinScale`、`scanIconMaxScale`、`loadValues()`、`onReload(...)` |

## `api`

| 类 | 职责 | 关键成员 |
|---|---|---|
| `SpiritInfoHolder` | 方块 BlockEntity 提供 AetherUI 悬浮信息 | `getSpiritInfo()` |
| `SpiritInfoLine` | 单行信息 + 所需灵视等级 | `isVisibleAt(int visionLevel)` |

| `ModArmorMaterials` | 魔力合金护甲材质 | 护甲材质注册常量 |
| `ModEnchantments` | 双击附魔注册 | 附魔注册常量 |
| `ManaToolTier` | 魔力工具 Tier | tier record 定义 |

| 类 | 职责 | 关键成员 |
|---|---|---|

| `AbstractNetworkNodeBlockEntity` | 节点公共基类 | `findParent()`、`findRootCore()`、`updateChildrenEfficiency()`、`disconnectChildren()`、`tickRelink()`，NBT 持久化 `LinkReason/RelinkAttempts` |
| `EfficiencyCalculator` | 范围与段效率 | `getMaxRange(NodeType)`、`calculateSegmentEfficiency(...)` |
| `OfflineCollectorData` | 离线聚集器影子 | `FULL_RATE_SECONDS`、`MAX_OFFLINE_SECONDS`、`MIN_OFFLINE_FACTOR`、`calculateOfflineGain(currentTick)`、`currentFactor(currentTick)` |

12 个 payload 的清单见 `04-网络与数据同步.md`。
